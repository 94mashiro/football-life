# 元进程(Meta-Progression)诊断:实测数据 + 设计裁决

> 背景:主创意见——"Roguelike 应该像杀戮尖塔/小丑牌那样,开局摸不到天花板,靠一局一局的积累才能到达巅峰。目前这块没做好。"
> 方法:① 用真实引擎跑蒙特卡洛(`meta-progression-sim.ts`,可复跑);② 对五款标杆 roguelite 的一手资料研究(`meta-progression-design.md`,全部带引用)。
> 基准:master @ d05fe89(含 b8ed8bc 赔率诚实/世界杯一生一战补丁)。n=1500/组,决策策略为确定性伪随机(各组同策略,组间对比公平;绝对值低估熟练玩家)。
> 日期:2026-08-08

---

## 一、裁决先行

**症状确认,药方修正。**

主创对症状的判断完全正确——本作目前**不存在成长曲线**:新号第一局的中位结果就是"传奇"档,世界杯夺冠率 67.7%,整个 meta 经济一局吃穿。"一局一局积累促成巅峰"的体验根本没有发生。

但研究结论对**药方**是个反转:主创点名的两款标杆(杀戮尖塔、小丑牌)恰恰是**零数值积累**的——它们跨局携带的没有任何一项是数值(详见研究文档 §1/§2)。"靠积累数值变强才能通关"是盗贼遗产(Rogue Legacy)模型,而它是五款里数据最差的一款(首通率 22.6%,玩家抱怨强制刷,设计师自认"稀释了 roguelike 精神")。**StS/小丑牌的"积累"是三样东西:内容广度(见过更多花样)、难度阶梯(赢了才能爬)、玩家自己的技术。单局强度上限从第 1 局到第 1000 局完全相同。**

所以正确的诊断是:**问题不是"缺少数值积累",而是"没有天花板"——第一局就把所有荣耀发完了,导致任何积累都无从谈起。** 先把天花板抬回去(把"赢"变稀有),再把积累轴从"数值"改到"内容+难度",曲线自然出现。

## 二、实测发现(引擎跑出来的,非感觉)

### 2.1 新号第一局就是天花板

| 指标 | 新号·零传承(n=1500) |
|---|---|
| 传承分 p50 | **602(= "传奇"档 ≥500)** |
| 传承分 p90 | 1094 |
| 世界杯夺冠率 | **67.7%** |
| 金球奖率 | 24.1% |
| 球神档(≥800)率 | **29.9%** |
| 巅峰 OVR≥90 | 16.3% |

对照:StS 全体玩家中**生涯首胜**达成率 66.5%、小丑牌 71.7%(Steam 全球成就,是"玩了很多局之后终于赢一次"的比例)。本作把同量级的"终极荣耀"(世界杯)以 67.7% 的概率发给**随机乱点的第一局**。

### 2.2 Meta 经济一局吃穿

| 门槛 | 数值 | 新号第一局(p50=602)够吗 |
|---|---|---|
| 全部 13 个祝福总价 | 465 | ✅ 一局买空全店 |
| 全部解锁门槛(国籍/天才档/祝福) | ≤200 | ✅ 全解锁 |
| 声望(Prestige)门槛 | 500 | ✅ 直接够到 |
| 升华解锁线 A5/A6/A7 | 400/520/650 | ✅ 中位一局解到 A6,p90 一局解到 A8 |

StS 的解锁曲线刻意做了"一局绝不连升两级"的 clamp(反编译源码证实),每角色 5,550 分铺满;本作等效于把 StS 几十小时的阶梯压缩进一局。

### 2.3 积累不但无用,而且为负:满配号比新号弱

| 组(n=1500,同种子) | 传承 p50 | 世界杯 | 球神率 |
|---|---|---|---|
| 新号·零传承 | 602 | 67.7% | 29.9% |
| **满配·全祝福+全声望** | **389(−213)** | 52.5% | 19.8% |
| 精选 9 数值祝福(无 build 型、无声望) | 864(+262) | 78.0% | 55.9% |

POWER 轴本身是正收益(+43%),但两个机制把它变成负资产:

1. **祝福无装备槽**:`App.tsx` 直接传 `meta.ownedBlessings`——买过即永久全开。玻璃大炮(伤病×3)、雇佣兵(留队无加成)这类 build 型祝福**买了就摘不掉**,花钱买永久 debuff。
2. **声望 perk 有两个实锤 bug + 一个近似死件**(逐 perk 隔离,n=800,基线 p50=594):

| 声望 perk | 单独效果(p50) | 判定 |
|---|---|---|
| pp_longevity 常青树("衰退延迟1年") | **120(−474)** | **恶性 bug**:`growthDelta` 把 `targetAge` 全程前移 2 年,等于把整条成长曲线错位,生涯直接报废(`sim.ts` declineDelay 实现) |
| pp_scout 青训球探("起始俱乐部+1档") | **428(−166)** | **设计陷阱**:更强俱乐部→坐板凳→大俱乐部替补成长三取最小(P-A16),16 岁进豪门 = 毁掉发育期 |
| pp_legacy_magnet 传承磁体("+10%") | 609(+15) | 描述说"所有传承分+10%",实际只乘在事件传承上(`run.ts:592`),≈死件;祝福"商业价值"同病 |
| 其余(prodigy/iron_will/transfer_savvy/boss_slayer) | +30~+75 | 正常正收益 |

**声望是本作最高层的长线系统("买空才开始"),而它发的 9 个永久奖励里 2 个毁号、1 个近似无效。** 玩家感知就是"积累没有意义"——主创的直觉在这里被数据精确解释了。

### 2.4 门是画上去的

- **天才档(wonderkid)解锁门槛(100 传承)实际不存在**:`run.ts:139` 硬编码 `allowWonderkid = true`,注释说"由 UI 把关",但 UI 从未把关——新号 41.6% 的局直接拿到最强成长档,而且这是概率最高的档位(39%)。
- **每日挑战不中和 meta**:`App.tsx:548` 把 `ownedBlessings` 和 `ascension` 原样传入每日局。同一天同种子,不同存档跑出不同生涯——榜单不可比。这正是研究文档 §7 里"别学 Dead Cells"的那个坑;StS 的做法是每日局 `treatEverythingAsUnlocked()` 全开并且不计入标准统计。种子分享同理:同 seed ≠ 同生涯,除非祝福/升华状态一致——"可分享、可复现"这个核心卖点已经被 meta 状态破坏了。

## 三、研究结论如何映射到本作(证据见 meta-progression-design.md)

| 研究原则 | 本作现状 | 差距 |
|---|---|---|
| P1 默认不做 POWER 轴,CONTENT+DIFFICULTY 足够(StS/小丑牌零数值) | 祝福+声望是纯 POWER 轴 | 方向反了 |
| P2 难度反哺解锁速度("打得越难解得越快",StS 每级 +5% 分) | 升华有 ×(1+0.15L) 乘数——**方向正确**,但基数崩了 | 保留,修基数 |
| P3 解锁给"奇怪"不给"更强"(Wild Strike 塞伤口牌) | 解锁给的是国籍/更强档位/更强祝福 | 需转向 |
| P4 解锁的正当理由是"课程表+清单",不是留存(LocalThunk 原话) | 登录奖励送传承、连登加成——纯留存件 | 违背 |
| P5 RPG 成长放在死亡之后(Rogue Legacy 唯一值得抄的一条) | 结算页→祝福商店动线已存在——**结构正确** | 保留 |
| P6 做了 POWER 就必须做拆除杆(Hades Routine Inspection) | 祝福买了永久全开,无法关闭 | 缺失 |
| P8 不可储蓄的货币产生退化 build | 传承可储蓄,此坑未踩 | ✅ |
| 附加 竞技/分享模式必须选一种 meta 语义(全开/只读) | 每日局半开(最差的那种) | 需修 |

## 四、设计方向(按优先级,前三条是曲线的骨架)

1. **把"赢"变稀有——压基线,这是一切的前提。** 目标参考:新号第一局中位落在"球员~明星"档(60–300),世界杯是 5% 量级的事件而非 68%;"球神"对标 StS A20 通关(全体 7.3%)。杠杆在 `sim.ts`/`data.ts` 的国家队与奖项基础概率、以及 `scoreLegacy` 的分档重标定。压完之后,升华乘数(P2,方向已对)自动变成"打得越难解得越快"的正循环。
2. **祝福改装备制,拆掉永久全开。** 局前从已拥有祝福里选 2~3 个带入(StS 遗物/小丑牌牌组的"build 宣言"),build 型祝福(玻璃大炮/雇佣兵)从负资产变成主动选择;同时天然提供了 P6 的拆除杆。这是一个 UI 改动 + `RunSetup.blessings` 已有通道,工程量小。
3. **修声望 perk 的两个 bug 和一个死件**(pp_longevity 的 declineDelay 实现、pp_scout 加成长保护或改效果、legacy_magnet 乘到总分)。长线层的奖励必须真的是奖励。
4. **解锁轴从"更强"转向"更多":** 传奇剧本、联赛、国籍、事件包按累计传承逐步开(课程表);wonderkid 门真正接线(`createRun` 读 unlock 而不是硬编码)。成就墙(已有 23 个)天然是"清单",往它上面挂解锁比挂数值健康。
5. **每日挑战与种子分享中和 meta**:每日局固定祝福集(全开或全关)+ 固定升华,分享种子编码 meta 状态或强制中和。二选一,别停在中间。

## 五、给下一个动手的会话

- 复跑数据:`npx tsx research/meta-progression-sim.ts`(环境变量 `N=` 控制样本量)。改平衡后先跑这个,看"新号第一局 p50"和"世界杯率"有没有真的下来。
- 本文数字会随平衡补丁漂移(写作当天就目击了 b8ed8bc 把世界杯率从 87%→68%)。**结论以结构性问题为准,数字以最新一次 harness 输出为准。**
