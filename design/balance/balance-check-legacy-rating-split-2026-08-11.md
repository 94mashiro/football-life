# Balance Check: 评级与货币分离 + 荣誉权重重排（P-RATING-SPLIT）

## 起因（业主观察）

一局 A10 生涯：巅峰 OVR 68、18 赛季、1 座西乙冠军、182 球、传承分 1912、含金量 ×11.59。
业主质疑：这种战绩为什么能拿到顶级加成？「传承加成若是奖励优秀生涯，就不该出现低战绩
但传承拉满。」

## 溯源（精确反解，非估算）

`scoreLegacy` 反解该局，工资项 = +22 时精确复现 165 → 1912：

| 输入 | 贡献 | 占比 |
|---|---:|---:|
| `max_overall` 68 | 68 | 41% |
| `seasons` 18 | 18 | 11% |
| 工资总额 + 终值 | 22 | 13% |
| `trophies` 西乙冠军 | 20 | 12% |
| `goals`/`assists` 182/56 | 12 | 7% |
| `awards`/`won_world_cup`/`won_ballon_dor` | 0 | 0% |
| 小计 | 140 | |
| × 弱国补偿（中国 youthTier 5） | ×1.18 | |
| **实绩** | **165** | |
| × A10 曲线（段 [113,259]→[166,1944]，斜率 31.79） | ×11.59 | |
| **传承分** | **1912** | |

诊断：**累积侧（赛季 18 + 工资 22 = 40）> 荣誉侧（20 + 12 = 32）**，且两侧对难度的反应
相反——累积侧对难度免疫（18 赛季在 A0/A10 一样能攒），荣誉侧被难度**删除**（飞升9
`"skip"` 让世界杯 120/洲际 55 恒为 0，飞升10 降档关掉金球路径）。于是「生涯表现 ×
难度加成」的前半句在高飞升发生词义漂移：从「我做成了什么」变成「我熬了多久 + 领了多少钱」。

## Health Summary: HEALTHY（有一条被实测否决的原假设，已如实记录）

7 条断言门全绿（难度 15 条 / 飞升经济 5 条 / climax / 体面退场 / preview / event-shape /
combo），行为指纹已 bless。

## 改动

1. **评级与货币分离**（根治「无名之辈=球神」同卡矛盾）。新增 `GameState.rawLegacy`
   = 同一生涯按飞升 0 结算的实绩。`legacy` 仍是货币（按设计随难度膨胀）。
   评级/称号/归档档位/榜单 rankName/菜单「最佳评级」全部改读实绩；
   `MetaSave.bestRunRaw` 为**可选**字段（不 bump VERSION，不清档；旧档回退 `bestRun`）。
   榜单排序仍用 `legacy`——`ORDER BY ascension DESC, legacy DESC` + 曲线在每档内
   严格单调（暴力验证 raw 0–3000，11 档无一处回落）⟹ 档内序恒等于实绩序。
2. **工资按荣誉封顶**：`wageCap = min(maxOverall × 2, honors)`。旧上限只锚 `maxOverall×2`
   （68 OVR ⇒ 136）而同局荣誉仅 32，公式允许工资是荣誉的 4.25 倍。
3. **前锋表现上限随奖杯柜放宽**：cabinet ≥ 60 保持 12（P-POS 的 GK/ST 平价不动），
   cabinet = 0 放宽到 45。「他们已通过金球/金靴兑现过」这个折扣的前提在高飞升不成立。
   斜率 (45−12)/60 = 0.55 < 1 ⟹ 总分对奖杯数仍严格单调（已验证），无「弃荣誉换上限」套利。
4. **飞升9「国家队退役」→「国家队弃子」**：不再 `"skip"`，改为入选门槛 +8（`ASC9_CALLUP_SURCHARGE`），
   climax 入口门槛与洲际决赛门槛同步抬高。难度档应该抬高门槛，不该删除事件。
5. **重标定 `ASCENSION_REWARD_CURVES`**（1–4 移动了 raw 分布，旧锚点过期）。

## 被实测否决的原假设（重要）

原设计意图是「飞升9 改造能把荣誉右尾还回去，右尾回来后段斜率自然变缓」。**实测否决：**

| 档 | 峰值OVR p50/p90/p99 | 世界杯% | 洲际% | 金球% | 平均奖杯柜 |
|---|---|---:|---:|---:|---:|
| A0 | 86/93/97 | 7.5% | 42.0% | 10.8% | 154 |
| A5 | 79/88/94 | 2.0% | 15.0% | 1.8% | 82 |
| **A8**（不含飞升9 惩罚） | 76/84/90 | **0.5%** | 5.7% | 0.7% | **47** |
| A10（含 +8 门槛） | 76/84/90 | 0.0% | 2.2% | 0.7% | 33 |

A8 根本不受飞升9 影响，右尾就已经塌到 0.5% / 奖杯柜 47。**压塌荣誉右尾的是「从严」取
三次最低 + 全面降级对 OVR 的压制，不是国家队那一档。** 改动 4 仍保留（它把 A9/A10 的
洲际路径从 0% 恢复到 2.2%，并恢复国家队生涯轨道 caps/goals/队长），但它不能重塑分布。

## 段斜率陡峭是算术后果，不是标定失误

实测 A10 稳策略 raw 跨度 p50→p99 = 153→369，而同分位溢价把 y 跨度钉在 372→4764。
要求的平均斜率 = (4764−372)/(369−153) ≈ **20**，即名义溢价 ×4.08 的 5 倍。

**加密锚点只会更糟**（11 锚点实测最陡 89.25 = ×21.9 名义溢价，4 锚点为 43.49 = ×10.7）——
窄 x 上摊宽 y 是矛盾本身。在业主同时坚持 (i)「A10 同分位 ≈ A0 ×4.08」与 (ii) A10 raw
跨度只有 A0 的 1/5 的前提下，「raw 每 +1 ≈ meta +20~40」是唯一解。

它**不伤榜单**（ascension-first + 单调 ⟹ 档内序恒等于实绩序），也**不再伤评级**（已改读实绩）。
要真正抹平需业主重定调：(a) 拓宽高飞升 raw 跨度（需削弱从严/全面降级），或
(b) 放弃 A10 ×4.08 锚（接受高飞升赚更少）。

## 反刷分地板必须锚在盲选 p65，不是 p50

盲选 p50 上方段斜率约 42，±3 raw 的抽样差让盲选中位结算值摆动 60%，
`blind.median ≤ 1.30` 门槛反复红（实测 2.186 → 1.597 → 仍红）。锚到 **p65** 后盲选主体
整段落在平台内，地板从「中位持平」升级为「整个盲选主体持平」且对抽样噪声免疫。

## 顺手修掉的两个真 bug

- **`DIGNIFIED_EXIT_MULT` 从未到过玩家手上**：`store.settleRun` 重算 `liveLegacy(ended)`
  时不传 `dignifiedExit`，再用结果覆盖 `ended.legacy`——体面退场 ×1.25 荣誉奖励在结算页、
  归档、meta、上传四处全部丢失。改为读引擎已结算好的 `ended.legacy`。
  影响：asc-0 传承中位 +8%（249→270）。
- **指纹测量的是玩家拿不到的分**：`tools/_harness.ts` 有同样的重算，`regress` 因此对上述
  bug 完全免疫。改为读 `g.legacy` / `g.rawLegacy`（后者进 canonical，故本次 100% 指纹churn）。

## Values That Need Attention（运营备忘）

- **锚点仍是 sim 标定**，且必须与 `ascension-economy-check` 的人群口径一致
  （`allowWonderkid: false`）——本次第一版用 `true` 标定，blind.median 直接红。
- **评级档未动**：球神 800 / 传奇 500 现在读实绩，含金量膨胀不再污染它，阈值语义终于稳定。
  但实绩分布本身因进球计分上移，`球神 ≈ 全人口 top 2%` 需在真人数据后重锚。
- **`bestRunRaw` 旧档回退 `bestRun`** 会一次性高估老玩家的「最佳评级」，随下一局刷新。
