## Question

建图 grilling 两轮：钉目的地 + 骨架分叉。

## Resolution

第一轮（目的地）：

1. 目的地 = 定版设计文档（过 design-review），实现在图外。
2. 词条与风格两层共存：**词条 = 选择的印记**（结果层，被动获得），**风格 = 主动经营的培养轴**（方向层）。
3. 培养感 = 开局定基调 + 途中低频深化（不新增操作密度，core-loop 红线）。
4. 替换范围不止轻事件：部分 contextual/叙事事件也让位。
5. 风格允许动成长曲线（不只是赔率/叙事）。

第二轮（骨架）：

6. 风格实体 = **词条树**（开局选起点词条，途中沿树深化）——不是静态原型身份，不是正交数值轴
   （数值轴会把玩家推回"数值比较"，正是反馈嫌弃的东西）。
7. 开局选择 = **生涯第一个 S 事件**（16 岁青年队，教练问"你想成为什么样的球员"），不加 setup 表单。
8. 深化节拍 = **固定 cadence（每 3~4 季）× 词条树条件门控** 双重门槛，占被砍事件的槽——
   替换而非叠加，总决策密度不升。
9. 成长机制 = **成长预算守恒重分配**：每季成长总量近守恒，风格决定分配形状（有得必有失）；
   不改天花板锚，不碰 A0/表现豁免两套已定版体系。
10. 砍除红线 = boss/climax（世界杯决战/决胜点球）、T 通道转会 cadence、判决类
    （medical_verdict/doctor_warning）、金球/退役弧线绝不动；让位候选 = 与"我怎么踢"语义
    重叠的成长型 contextual（王座挑战/位置竞争/让位死守等），具体清单见票 002。
