## 一页图

```
16 岁开局（青年队教练:「你想成为什么样的球员?」）
│
├── 天骄线（为巅峰燃烧）        ├── 匠人线（千锤百炼）          ├── 大心脏线（为大场面而生）
│   T1 天赋觉醒                 │   T1 千锤百炼                 │   T1 大心脏
│   T2 万众瞩目                 │   T2 常青之躯                 │   T2 关键先生
│   T3 ┬ 加冕为王               │   T3 ┬ 不老传说               │   T3 ┬ 决赛之王
│      └ 涅槃（救赎线）         │      └ 精神图腾               │      └ 国家英雄
│
└── 顺其自然（无风格 — 保持现状行为，control 组）

GK 不开第四条树: 同三线换皮（门神天成 / 门线常青 / 点球克星），数值减半适配。
```

**形态: 3 条风格线 × 深度 3，顶层二选一 capstone = 12 个词条节点 + GK 换皮。**
不按位置族分支——位置已是开局输入，按位置分支会让选择变成假选择（ST 必选射手线）。
三条线对任何位置都成立，只是收益侧重不同 → 位置 × 风格才构成真组合空间。

## 分支明细

### 天骄线 — 早燃烧、高峰值、名利场

| 节点 | 门控 | 赔率/成长修正（⚠占位） | 结算加成 |
|---|---|---|---|
| T1 天赋觉醒 | 开局选定 | 成长重分配: ≤22 岁区间上限 +1；衰退提前一周期（~28 起）。金球/金靴赔率 ×1.15。转会报价档次上浮 | — |
| T2 万众瞩目 | 23 岁前 OVR≥80 | 个人奖赔率再 ×1.15；加 tag `media_darling`（门控名利风味事件） | — |
| T3a 加冕为王 | 金球 or 联赛冠军 | 金球赔率封顶再放宽 | scoreLegacy 巅峰段位项 ×1.1 |
| T3b 涅槃 | 重伤经历 or OVR 自峰值跌 ≥5 | 衰退推迟一周期（回补 T1 的代价） | 「王者归来」叙事 + 结算加成 |

不是死路，是另一个故事（roguelike 的 run 内叙事弧）。

### GK 特例 — 换皮不换树

GK dev profile 强制 normal、成长表平坦，第四条独立树不值得（内容 ×4 但只服务 1/12

| 原线 | GK 皮 | 适配 |
|---|---|---|
| 天骄 | 门神天成 | 个人奖映射到金手套；成长重分配幅度减半（GK 表平，全额会失真） |

| 大心脏 | 点球克星 | climax 对 GK = 扑点/决赛零封，decisivePenalty 语义天然成立 |

## 事件形态

- **开局事件（16 岁）**: 生涯第一个 S 事件，青年队教练发问。纯身份选择、**无赔率**
  （这是承诺不是赌局）；每个选项的 sub 写明「得什么 / 失什么」（机会成本可见，P0 红线）。
  第四选项「顺其自然」= 无风格，行为等于现状（regression 对照组 + 不想承诺的玩家）。
- **深化事件**: 走 S 通道，占被砍事件的槽（清单见票 002）；优先级低于判决/climax、
  高于 pool。cadence 到期 **且** 门控达标才触发；未达标 → 静默跳过，下个 cadence 重试。
  深化本身带赔率（⚠占位 70%）: 成功晋级下一层；失败不惩罚——下个 cadence 再来 +
  小额安慰（叙事/+1 表现分），调参往正向靠。
- **T3 分叉**: 达标时事件给二选一（两个 capstone 都亮出门控与收益），选一封另一。

## 与既有系统的接口

- **成长重分配** = 在 `growthDelta` 的区间查表后加风格偏移（±1 上限 / 衰退 onset ±1
  周期），复用 declineDelay 既有机制——不改天花板锚，不碰 A0/表现豁免。
- **赔率修正显式可见**: 走 `clubTrophyCandidates` 同源（combo 定版原则），UI 直接看到
  ×1.1 后的数字；是否标注来源见票 007（隐形保底原则是否适用）。
- **结算加成**: capstone 只作为 `scoreLegacy` 的输入项（legacy 绝不做事件 mod），
  具体权重接线归票 008。
- **词条 vs 印记**: 树节点是「风格」（主动经营）；既有 tags（fan_darling/captain/
  compromised_body…）仍是「印记」（被动获得），两层在球员卡上应分区展示（UI 层等
  成型后另开票，见图上雾区）。
