# 位置平衡：修可见性/上限信号，不动传承公式

玩家反馈"中锋是高评价生涯的唯一解"。实测（飞升 0/5/9，随机与最优玩法）证伪了前提——GK/边中/CAM 稳定领先、ST 排中下游；传承轴对非前锋已**过度补偿**（随机中位 CB 252 > ST 218；最优玩法 GK 进球神 5% vs ST 1%）。真正问题是**可见性/上限信号全偏前锋**：单场评分前锋冲 9.0+ 而后卫卡 ~8.0、市场价值、金球金靴头条、16 岁起存在感——而非前锋的补偿（后卫 +30、GK 零封/2）埋在传承公式里看不见。决策：修可见性与上限信号，**不**动 `scoreLegacy`/`careerPerfLegacy`/forced-exit/单场评分公式/TOTY（均已位置公平，或刻意保留前锋上限作足球真实）。

## 考虑过的替代方案（均拒绝）

- **重平衡传承数字给非前锋加分**：传承轴已过度补偿非前锋（中位 CB > GK > ST），再加只会让中位更偏；且治标不治本——玩家读的是可见/上限信号，不是埋在公式里的补偿分。
- **抬非前锋单场评分上限到 ~9.0**：后卫 9.0 不足球真实；会动 forced-exit 中位（须只抬上限不抬中位，脆弱），触 regress。
- **加位置皇冠奖（金盾/金钥匙）**：让后卫中位传承进一步过头，且现实无与金球同级的后卫奖。生涯荣誉墙皇冠保持前锋(+GK)专属是**接受的边界**——后卫的可见头条在赛季级（MVP + 巅峰 chip + TOTY）。

## 做法

1. **位置专属巅峰数据**作联名头牌（每组一个，全已 tracked）：前锋(LW/RW/ST)→进球、组织(LM/RM/CAM)+CM→助攻、防守(CB/LB/RB/CDM)+GK→零封。比赛内英雄卡 + 青年队赛季卡(16-19，无 chip) + 生涯总结「生涯最佳 X·位置称号」三处都推；精英赛季(阈值从数据 p90 推)给 chip+foil，**不**弹全屏里程碑。
2. **MVP `statGreat` 门槛位置感知**（唯一引擎改动，`run.ts`）：后卫(CB/LB/RB/CDM)改用零封、GK 从 ≥22 改成 ≥17，二者共用一个零封精英门槛；组织沿用进球+助攻≥25、前锋沿用进球≥28。伟大后卫能拿联赛 MVP（VVD 式）；**副作用红利**——MVP 喂评分(+0.5)+市场价值，顺带缩小市场价值前锋偏。
   - **阈值由来（数据，非手填）**：实测首赛季零封分布 p50=14、p90=17、max≈21（`csProb` 上限 0.5 × ~38 场 ≈ 16，结构上限在此）。`cs≥17` 对应 DEF 14.2%、GK 17.7% 的首赛季占比，与前锋 `goals≥28` 的 15.2% **几乎同率**——三档精英门槛统一在「约 15% 首赛季可达」，内一贯。
   - **附带修一个潜在 bug**：原 GK 门槛 `cleanSheets ≥ 22` 实测 **0% 可达**（max 21），即 GK 的「精英赛季 14% MVP 路径」长期失效，GK 只能走 3% 底线。`≥22` 是未对照分布定的校准错误。改 ≥17 后 GK MVP 生涯率从≈0 升到 ~35%（伟大门神几季一个，不离谱——金球/金手套 GK 已能拿）。

## 后果

- 招牌数据露面 + chip + 青年卡：纯 UI 渲染现有 `SeasonStats` → **regress 安全**（行为/文案指纹都不动）。属 UI/UX 改动，须先过 `impeccable` + `ui-ux-pro-max` 出设计稿再写码。
- MVP 门槛：引擎机制改动 → 先过 `game-design-core` + `roguelike`，改完跑 `balance-check`；动 MVP→评分→市场价值，**可能触行为指纹，需 `regress:bless`（预期内）**。
- 调参项（从数据推，非设计决策）：精英阈值（如零封≥18/助攻≥18/进球≥30）、MVP 后卫零封阈值。
